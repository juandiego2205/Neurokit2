# Introducción a NeuroKit2 - UDEA

Este repositorio contiene un tutorial introductorio sobre [NeuroKit2](https://neurokit2.readthedocs.io/), una biblioteca de Python diseñada para el procesamiento y análisis de señales fisiológicas como:

- Electrocardiograma (ECG)
- Electromiografía (EMG)
- Actividad electrodérmica (EDA)
- Señales respiratorias (RESP)

Esta guía práctica está dirigida a estudiantes e investigadores interesados en neurociencia computacional, bioseñales y análisis de datos fisiológicos.

## Señales simuladas en el tutorial

- ECG: Simulación de señales con distintas frecuencias cardíacas y niveles de ruido.
- EMG: Simulación de actividad muscular con diferentes configuraciones de ráfagas.
- EDA (Electrodermal Activity): Señales relacionadas con la respuesta del sistema nervioso simpático.
- RESP (Respiración): Simulación de patrones respiratorios con parámetros ajustables.

## Recomendaciones de uso

Para seguir el tutorial:

1. Clona este repositorio.
2. Abre el archivo `Introduccion_NeuroKit2_UDEA_ipynb.ipynb` con Jupyter Notebook o un entorno compatible.
3. Instala las librerías necesarias (`neurokit2`, `matplotlib`, `pandas`, `seaborn`) si aún no lo has hecho.
4. Ejecuta cada celda para visualizar y analizar las señales simuladas.
